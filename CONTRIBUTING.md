# Contributing

Open an issue describing the observed behaviour, browser/OS and a minimal reproduction. State whether a report concerns the renderer, controls or numerical model.

For a change, keep SI units explicit, update the relevant documentation, and run `pnpm test` and `pnpm build`. For rendering changes, include an actual application capture. Test physical claims against measurements before adding them to the README. Do not add decorative pass badges, fabricated hardware results or unrelated features.

The project currently has no selected open-source licence. Agree contribution and reuse terms with the maintainer before submitting substantial work.
